# Balatro — Minecraft 小丑牌插件

在 Minecraft 中游玩《小丑牌》(Balatro) 的扑克构筑 Roguelike：打牌计分、收集小丑与消耗品、挑战 Boss 盲注，通关 8 个底注。

## 环境要求

- **Minecraft 26.2**（Paper 或 Papo 服务端）
- **Java 25**

## 安装

1. 将 `balatro-0.4.61.jar` 放入服务端的 `plugins/` 目录。
2. 重启服务器。

## 开始一局

```
/balatro gui
```

打开图形界面开局向导：点击物品依次选择 **模式（标准/挑战）→ 牌组（15）→ 赌注（0~7）→（挑战）→ 种子**，确认后开始。种子默认随机，可指定以复现同一局。

也可以用命令直接开局（参数顺序不限，自动识别）：

```
/balatro play [牌组] [赌注] [挑战] [种子]
```

执行后，你面前会生成一张专属全息牌桌（仅自己可见，他人看不到）。

## 怎么操作（全息牌桌）

面对牌桌，用**右键**点击牌面即可，无需任何指令：

| 操作 | 作用 |
|---|---|
| **右键** | 使用 / 操作（选中手牌、购买商品、使用消耗品、出售小丑、出牌、弃牌…） |
| **Shift + 右键** | 查看该卡的详细简介（显示在聊天框） |

> 进入商店或开启补充包时，所有卡的简介会自动列在聊天框，方便你判断要买/选哪张。
>
> **确认框两步流**：右键持有的小丑（出售）、右键消耗品（使用/出售）不会立即执行——
> 聊天框会先弹出该卡详情与可点击的 **[确认]** 按钮（附售价/说明），点击后才真正执行，
> 期间可点 **[取消]**。这是防误触设计；购买商品、选牌、按钮等其他操作仍是一步直达。
>
> **目标类消耗品**（塔罗增强/死神/蜡封/光环造镭射等）：先**右键手牌选中目标**，再右键消耗品
> 确认——确认按钮会**自动带上已选牌**（并提示「需选中 N 张手牌」）。商店阶段右键消耗品
> 的确认框同时提供 **[确认出售]** 与 **[确认使用]**（使用限无目标类：星球/非目标塔罗/部分幻灵）。

## 一局怎么玩

1. **出牌**：右键选中手牌（牌会上移高亮）→ 右键「出牌」按钮计分。
2. **达成目标分**即通过当前盲注，进入**商店**。
3. 在商店右键购买 **小丑 / 消耗品（塔罗·星球·幻灵）/ 补充包 / 优惠券**，强化你的牌组。
4. 继续挑战下一个盲注（小→大→Boss），通过 **8 个底注（ante）** 即通关。

## 命令参考

命令 `/balatro`（别名 `/blt`、`/joker`），仅玩家可用。全息右键是主要玩法，下表命令为**等价的备用操作**（全息交互不便时使用）。所有「序号」均为 **从 1 开始**。

> 在游戏内输入 `/balatro` 或 `/balatro help` 时，把**鼠标悬停**在聊天框的命令令牌上可查看该命令的详细说明与使用举例，**点击**可直接回填到输入框。

### 通用

| 命令 | 参数 | 说明 |
|---|---|---|
| `gui` | — | 打开图形界面开局向导（推荐新手）。别名 `menu` |
| `play` | `[牌组] [赌注] [挑战] [种子]` | 开始一局（默认红牌组 / 白注 / 随机种子）。参数顺序不限，自动识别 |
| `quit` | — | 放弃当前局（下线也会自动放弃） |
| `status` | — | 查看当前局面（盲注 / 分数 / 手牌）。别名 `hand` |
| `endless` | — | 通关 ante 8 后进入无尽模式 |
| `top` | — | 查看排行榜前 10（按玩家聚合：最高底注·通关次数） |
| `version` | — | 查看版本号、作者、开源协议与地址。别名 `ver` |
| `help` | `[页码 \| 命令名]` | 分页帮助 / 单命令详情。别名 `?` |

### 出牌回合

| 命令 | 参数 | 说明 |
|---|---|---|
| `playcard` | `<序号...>` | 出牌：1–5 张手牌序号（空格分隔）。如 `playcard 1 2 3`。别名 `pc` |
| `disc` | `<序号...>` | 弃牌：手牌序号。别名 `discard` |

### 盲注选择

| 命令 | 参数 | 说明 |
|---|---|---|
| `go` | — | 开始当前盲注 |
| `skip` | — | 跳过当前盲注并获得 1 个随机标签（Boss 盲注不可跳过） |

### 商店阶段

| 命令 | 参数 | 说明 |
|---|---|---|
| `shop` | — | 列出商店全部商品与价格 |
| `buy` | `<序号>` | 购买商店第 N 张卡牌（小丑/游戏牌/塔罗/星球/幻灵） |
| `buybag` | `<序号>` | 购买第 N 个补充包。别名 `pack` |
| `buyvoucher` | `[券序号]` | 购买优惠券。商店只有 1 张券时可省略序号；多张时需指定。别名 `voucher` |
| `reroll` | — | 重掷商店（消耗金钱） |
| `next` | — | 离开商店，进入下一盲注 |

### 消耗品 / 小丑 / 补充包

| 命令 | 参数 | 说明 |
|---|---|---|
| `cons` | — | 列出持有的消耗品（塔罗/星球/幻灵）。别名 `consumables` |
| `use` | `<消耗品序号> [手牌序号...]` | 使用消耗品；需指定目标手牌的也在这里传手牌序号 |
| `sellc` | `<序号>` | 出售第 N 个消耗品 |
| `sellj` | `<序号>` | 出售第 N 个小丑 |
| `packs` | — | 查看正在开启的补充包内容（补充包阶段） |
| `pick` | `<序号>` | 从补充包选第 N 张 |
| `skipack` | — | 跳过当前补充包 |

> 示例：`/balatro play ABC123` 用种子 ABC123 开局；`/balatro playcard 1 5` 打出第 1、5 张牌；`/balatro use 1 2 3` 使用第 1 个消耗品、作用于第 2、3 张手牌。

## 权限

- `balatro.play`（默认：所有人）— 开始 / 退出一局（可用权限插件如 LuckPerms 撤销；撤销后命令被拒且 Tab 不补全，不产生会话）
- `balatro.admin`（默认：管理员）— 预留（当前版本尚无管理命令，仅声明）

## 可选集成

- 安装 **Vault**（+任一经济插件如 EssentialsX）后自动接入服务器经济：过关奖励按
  `config.yml` 的 `reward.economy.*` 发放（默认 清盲 $1 / 清底注 $10 / 通关 $100，
  可整体关闭或按档调整）。

## 给开发者

本插件提供扩展 API（自定义事件 + 经济/统计/排行榜/奖励服务接口），供第三方插件接入排名、奖励、经济联动等功能，**无需 fork**。详见 [API.md](API.md)。

性能基准位于 [`benchmark/`](benchmark/README.md) 子项目（固定种子方法论 + best-of-3 交错对比协议），可用于量化引擎改动的性能影响。
